# Time Complexity

| Scenario | Time Complexity | Description |
| :--- | :--- | :--- |
| Best Case | O(n log n) | The array is divided and merged efficiently |
| Average Case | O(n log n) | The array is repeatedly divided into smaller parts and merged |
| Worst Case | O(n log n) | All elements are divided and merged |

# Space Complexity

| Space Complexity |
| :--- |
| O(n) |

# Conclusion

Merge Sort divides the array into smaller parts until each part contains one element. It then merges the smaller sorted parts to produce the final sorted array. Its best-case, average-case, and worst-case time complexity is **O(n log n)**. The space complexity is **O(n)**.
