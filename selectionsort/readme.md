# Time Complexity

| Scenario | Time Complexity | Description |
| :--- | :--- | :--- |
| Best Case | O(n²) | The algorithm compares all remaining elements to find the minimum |
| Average Case | O(n²) | Multiple comparisons are needed to find the minimum element |
| Worst Case | O(n²) | The algorithm still compares all remaining elements |

# Space Complexity

| Space Complexity |
| :--- |
| O(1) |

# Conclusion

Selection Sort repeatedly finds the smallest element from the unsorted part of the array and places it in the correct position. Its best-case, average-case, and worst-case time complexity is **O(n²)**. The space complexity is **O(1)**.
