# Time Complexity

| Scenario | Time Complexity | Description |
| :--- | :--- | :--- |
| Best Case | O(n log n) | Heap is built and elements are extracted one by one |
| Average Case | O(n log n) | Heap operations are performed for all elements |
| Worst Case | O(n log n) | Each element requires heapify operations |

# Space Complexity

| Space Complexity |
| :--- |
| O(1) |

# Conclusion

Max Heap Sort first builds a Max Heap and then repeatedly moves the largest element to the end of the array. Its best-case, average-case, and worst-case time complexity is **O(n log n)**. The space complexity is **O(1)**.
