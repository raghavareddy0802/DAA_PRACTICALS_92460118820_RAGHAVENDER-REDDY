# Time Complexity

| Scenario | Time Complexity | Description |
| :--- | :--- | :--- |
| Best Case | O(1) | Element is found at the first index |
| Average Case | O(n) | Element is found somewhere in the middle |
| Worst Case | O(n) | Element is at the last index or does not exist |

# Space Complexity

| Space Complexity |
| :--- |
| O(1) |

# Conclusion

Linear Search checks elements one by one. Its best-case time complexity is **O(1)**, while average and worst-case time complexity is **O(n)**. The space complexity is **O(1)**.
