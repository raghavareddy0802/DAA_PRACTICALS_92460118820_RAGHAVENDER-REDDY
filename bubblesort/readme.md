# Time Complexity

| Scenario | Time Complexity | Description |
| :--- | :--- | :--- |
| Best Case | O(n) | Array is already sorted, so no swapping is needed |
| Average Case | O(n²) | Elements require multiple comparisons and swaps |
| Worst Case | O(n²) | Array is in reverse order |

# Space Complexity

| Space Complexity |
| :--- |
| O(1) |

# Conclusion

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. Its best-case time complexity is **O(n)**, while average and worst-case time complexity is **O(n²)**. The space complexity is **O(1)**.
