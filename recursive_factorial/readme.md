| Average Case | O(n) | The function makes n recursive calls |
| Worst Case | O(n) | The function makes n recursive calls |

# Space Complexity

| Space Complexity |
| :--- |

# Conclusion

The Recursive Factorial method calculates the factorial by calling the same function repeatedly until it reaches the base condition. Its best-case, average-case, and worst-case time complexity is **O(n)**. The space complexity is **O(n)** because recursive function calls use the call stack.
