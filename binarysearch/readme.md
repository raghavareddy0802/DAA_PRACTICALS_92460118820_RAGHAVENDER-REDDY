# Time Complexity

| Scenario | Time Complexity | Description |
| :--- | :--- | :--- |
| Best Case | O(1) | Element is found at the middle position |
| Average Case | O(log n) | The search space is repeatedly divided into half |
| Worst Case | O(log n) | Element is not found or found after maximum divisions |

# Space Complexity

| Space Complexity |
| :--- |
| O(1) |

# Conclusion

Binary Search works by repeatedly dividing the sorted array into two halves. Its best-case time complexity is **O(1)**, while average and worst-case time complexity is **O(log n)**. The space complexity is **O(1)**.
